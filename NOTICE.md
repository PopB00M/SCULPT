# Notice

This repository contains research code for SCULPT.

Third-party components used by the pipeline include PyTorch, DGL, Hugging Face Transformers, FAISS, NetworkX, scikit-learn, pandas, NumPy, tqdm, and the OpenAI Python SDK.

The default code embedding model is `Salesforce/codet5p-110m-embedding`. Users are responsible for complying with the license and usage terms of any pretrained models, datasets, and LLM services they use.

The full vulnerability dataset is not redistributed in this repository. See `DATA.md`.
